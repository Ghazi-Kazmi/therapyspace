# Therapy Space - CV Project Description

**Therapy Space** is a full-stack mental wellness web application built with React, TypeScript, and Tailwind CSS, providing users with a comprehensive mental health tracking platform featuring mood tracking, AI-powered chatbot support, digital journaling, meditation tools, progress analytics with data visualization, gratitude journaling, daily affirmations, and self-care reminders, along with gamified achievement tracking, accessibility features (dark mode, text-to-speech, responsive design), and secure local data storage for user privacy.
