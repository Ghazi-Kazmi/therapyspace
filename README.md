# Therapy Space - Mental Wellness Companion

A comprehensive React + Vite application for mental wellness and therapy support, built from Figma designs.

## 🌟 Features

- **Mental Wellness Dashboard** - Comprehensive tools for mental health tracking
- **Mood Tracker** - Track and analyze your emotional patterns
- **AI Chatbot** - Intelligent conversational support
- **Journal** - Digital journaling with privacy focus
- **Calm Zone** - Meditation and relaxation tools
- **Progress Analytics** - Visual insights into your wellness journey
- **Daily Affirmations** - Positive reinforcement system
- **Gratitude Journal** - Practice gratitude with guided prompts
- **Achievements & Streaks** - Gamified wellness tracking
- **Self-Care Reminders** - Personalized wellness notifications
- **Community Stories** - Shared experiences and support
- **Resources** - Curated mental health resources
- **Accessibility Features** - Dark mode, font sizing, text-to-speech

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd therapy-space
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

## 🛠️ Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## 🏗️ Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Charts**: Recharts
- **Form Handling**: React Hook Form + Zod
- **Notifications**: Sonner
